Where: Data Sources

The primary dataset comes from the U.S. Securities and Exchange Commission (SEC) EDGAR system, using the CompanyFacts API. This API provides standardized XBRL financial statement data for publicly traded companies without requiring an API key. We selected 40 large companies across eight sectors to ensure diversity.

Other data sources (macroeconomic indicators, market data, news sentiment) will be added in subsequent steps.

How: Data Collection & API

We used Python to interact with the SEC API. The script performs the following steps:

  1. Fetch the official company ticker → CIK mapping from company_tickers.json.
  2. Select a list of tickers (40 companies).
  3. For each company, call the CompanyFacts endpoint:
    https://data.sec.gov/api/xbrl/companyfacts/CIK{cik}.json
  4. Extract key US-GAAP financial metrics from the latest 10-K filing.
  5. Compute derived ratios (ROA, ROE, debt-to-equity, profit margin).
  6. Save raw and clean CSV files.

The full Python script is available at code/company_financials.py.

Why

The project aims to understand the drivers of financial performance in publicly traded companies. Financial statements provide the fundamental measures of performance (e.g., profitability, leverage, liquidity). By combining them with market and macroeconomic data later, we can build machine learning models to identify which factors are most associated with company success.

Raw Data

The raw data, exactly as returned by the SEC API, is stored in:

  • company_financials_raw.csv

This file contains one row per company (latest fiscal year) with raw financial values in USD.

Data Preparation

Cleaning steps performed in Python:

  • Converted numeric columns to float.
  • Removed rows where critical values were completely missing (if any).
  • Computed derived metrics:
    • ROA = Net Income / Total Assets
    • ROE = Net Income / Total Equity
    • Debt-to-Equity = Long-Term Debt / Total Equity
    • Profit Margin = Net Income / Revenue
  • Added a sector column based on ticker (manual mapping).

The clean dataset is stored in:

  • company_financials_clean.csv

Missing values are retained for now; they will be handled during modeling (e.g., imputation or dropping columns with excessive missingness).

# Initial Findings

- The dataset contains **40 companies** across **8 sectors**.
- Some financial metrics are missing for certain companies (e.g., long-term debt may be zero or not reported separately).
- ROA varies widely by sector; technology and healthcare often show higher ROA, while utilities and energy have lower ROA.
- There is a positive relationship between revenue and net income, as expected, but the spread suggests other factors (e.g., margins, industry) also matter.
- These initial observations set the stage for integrating additional data sources and building predictive models in later modules.
