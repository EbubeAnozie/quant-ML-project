Boosting Decision Stumps to Classify High-ROA Firms

Overview

Boosting is an ensemble method that builds models sequentially, where each new model focuses on the examples the previous ones got wrong. This differs from bagging, which builds trees in parallel on bootstrap samples and averages them.

AdaBoost uses decision stumps, a low variance, depth-1 trees. After each round, misclassified rows get higher weight and correctly classified rows get lower weight, so the next stump is forced to focus on hard cases. Each stump gets a weight α based on its weighted error: \(\alpha = \tfrac12 \ln\!\frac{1-\epsilon}{\epsilon}\). So, a lower error means larger α. Predictions are combined as a weighted vote \(\hat y = \operatorname{sign}\!\big(\sum_t \alpha_t\, h_t(x)\big)\). Stumps that performed better have more say.

Code

The Python script is saved at code/adaboost_model.py.

Code 
train = pd.read_csv("data/clean/train_adaboost.csv")
test  = pd.read_csv("data/clean/test_adaboost.csv")

num = ["Debt_to_Equity","Profit_Margin","log_Assets"]
cat = ["sector"]
pre = ColumnTransformer([("num","passthrough",num),
                         ("cat", OneHotEncoder(handle_unknown="ignore"), cat)])

def make_ada(n, lr):
    return Pipeline([("pre", pre),
        ("m", AdaBoostClassifier(
            estimator=DecisionTreeClassifier(max_depth=1),
            n_estimators=n, learning_rate=lr, random_state=42))])

tr, val = train_test_split(train, test_size=0.25, random_state=1,
                           stratify=train["HighROA"])
rounds = [10, 25, 50, 100, 200, 400]
accs = {lr: [] for lr in [0.1, 0.5, 1.0]}
for lr in accs:
    for n in rounds:
        m = make_ada(n, lr).fit(tr[num+cat], tr["HighROA"])
        accs[lr].append(accuracy_score(val["HighROA"], m.predict(val[num+cat])))

best = max(((lr, n) for lr in accs for n in rounds),
           key=lambda t: accs[t[0]][rounds.index(t[1])])
print("best (learning_rate, n_estimators) =", best)

final = make_ada(best[1], best[0]).fit(train[num+cat], train["HighROA"])
pred = final.predict(test[num+cat])
cm = confusion_matrix(test["HighROA"], pred)
acc = accuracy_score(test["HighROA"], pred)
#print("AdaBoost test accuracy =", round(acc, 4))
#print("Confusion matrix:\n", cm)
best (learning_rate, n_estimators) = (0.1, 25)

(e) Conclusions

AdaBoost’s test accuracy of 0.5000 is not a stable estimate because of the data size. The margin remains the dominant feature, consistent with the linear and logistic results. Margin efficiency is the strongest green flag for financial performance. Also, leverage is a much weaker signal than the “more debt means more risk” story would predict. In summary, the effect of leverage and sector depends on the firm’s margin profile.

## Overview

**Boosting** is an ensemble method that builds models *sequentially*,
where each new model focuses on the examples the previous ones got wrong.
This differs from **bagging**, which builds trees *in parallel* on bootstrap samples and averages them.

AdaBoost uses **decision stumps**, a low variance, depth-1 trees. After each round, misclassified rows get *higher weight*
and correctly classified rows get *lower weight*,
so the next stump is forced to focus on hard cases. Each stump gets a **weight α** based on its weighted error:
$\alpha = \tfrac12 \ln\!\frac{1-\epsilon}{\epsilon}$. So, a lower error means larger α. Predictions are combined as a
weighted vote $\hat y = \operatorname{sign}\!\big(\sum_t \alpha_t\, h_t(x)\big)$. Stumps that performed better have more say.
