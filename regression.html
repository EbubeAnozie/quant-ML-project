Linear and Logistic Regression on the Company-Year Panel

Overview

Linear regression predicts a continuous numeric outcome by fitting a straight line (or hyperplane) that minimizes squared error. Here, it predicts ROA from firm characteristics. Logistic regression predicts the probability that an observation belongs to a two-class category. Here, it predicts P(HighROA = 1).

Linear regression outputs any real number and is scored with RMSE and R².

Logistic regression outputs a probability in [0, 1] and is scored with accuracy and a confusion matrix. Logistic regression computes a linear score \(z = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k\), then applies the sigmoid \(\sigma(z) = \frac{1}{1+e^{-z}}\) to map \(z\) into a probability. A threshold (usually 0.5) converts that probability into a class by predicting 1 if \(\sigma(z) \ge 0.5\), else 0.

Code 
z = np.linspace(-8, 8, 400); s = 1/(1+np.exp(-z))
fig, ax = plt.subplots(figsize=(6,4))
ax.plot(z, s, lw=2)
ax.axhline(0.5, color="gray", ls="--"); ax.axvline(0, color="gray", ls=":")
ax.fill_between(z, 0.5, s, where=s>=0.5, alpha=.15, color="green", label="predict 1")
ax.fill_between(z, s, 0.5, where=s<0.5, alpha=.15, color="red",   label="predict 0")
ax.set(title="Sigmoid: z → σ(z)", xlabel="z", ylabel="σ(z)")
ax.legend(); plt.tight_layout(); plt.show()

Data Prep

The dataset is saved as data/clean/regression_data.csv. Rows with missing values in any of Debt_to_Equity, Profit_Margin, log_Assets, ROA, or sector were dropped before saving.

A sample of the first 10 rows is shown below.

The two models need different kinds of label, so regression_data.csv carries one column for each.

  • Linear regression: Return on assets is a continuous ratio (e.g. 0.072 for 7.2%), so it is directly usable as a regression target.
  • Logistic regression: HighROA = 1 if a company’s ROA is above the training-set median ROA, and 0 otherwise. The threshold is computed after the split, from the training rows only.

Both models use the same feature columns: Debt_to_Equity, Profit_Margin, log_Assets, and a one-hot encoded sector.

The labeled data is split 80/20 with random_state=42, giving roughly 32 training rows and 8 test rows for the 40-row sample. The two sets are shown side by side below:

The two split files are linked here: data/clean/train_regression.csv and data/clean/test_regression.csv.

train_test_split assigns each row to exactly one of the two sets, so no company-year observation appears in both. They must be disjoint because if a row were in both, the model could partially memorize it during training.

Code

The full Python script is saved at code/regression_models.py.

Code 
train = pd.read_csv("data/clean/train_regression.csv")
test  = pd.read_csv("data/clean/test_regression.csv")

num = ["Debt_to_Equity","Profit_Margin","log_Assets"]
cat = ["sector"]
pre = ColumnTransformer([("num","passthrough",num),
                         ("cat", OneHotEncoder(handle_unknown="ignore"), cat)])

lin = Pipeline([("pre", pre), ("m", LinearRegression())]).fit(train[num+cat], train["ROA"])
pred_lin = lin.predict(test[num+cat])
rmse = root_mean_squared_error(test["ROA"], pred_lin)
r2   = r2_score(test["ROA"], pred_lin)

log = Pipeline([("pre", pre), ("m", LogisticRegression(max_iter=1000))]).fit(train[num+cat], train["HighROA"])
pred_log = log.predict(test[num+cat])
acc = accuracy_score(test["HighROA"], pred_log)
cm  = confusion_matrix(test["HighROA"], pred_log)

names = num + list(lin.named_steps["pre"].named_transformers_["cat"].get_feature_names_out(cat))
coefs_lin = dict(zip(names, lin.named_steps["m"].coef_))
coefs_log = dict(zip(names, log.named_steps["m"].coef_[0]))

#print(f"Linear   RMSE = {rmse:.4f}   R² = {r2:.4f}")
#print(f"Logistic accuracy = {acc:.4f}")
#print("Confusion matrix:\n", cm)

Two coefficients in plain words.

  • Profit_Margin (β = 0.3454). The one coefficient with a real magnitude. Holding the other features fixed, a company with a profit margin 10 percentage points higher is associated with an ROA about 3.5 points higher.
  • Debt_to_Equity (β = 0.0019). Holding the other features fixed, a one-unit higher debt-to-equity ratio is associated with an ROA only 0.19 points higher.

  • Test accuracy = 0.6250 on 8 test companies. The model made 0 false positives but missed half of the true high performers (3 false negatives). When it calls a firm a top performer it tends to be right, but it under-calls.

Naive Bayes accuracy was 0.75. It looks like naive bayes performs better than logistic regression which has an accuracy of 0.6250. But with only 8 test rows, both numbers carry wide uncertainty. Thus, the two models performed comparably.

Conclusions

Profit_Margin dominates every other coefficient. In the linear regression, a company with a profit margin 10 percentage points higher is associated with an ROA about 3.5 points higher (β = 0.3454). In the logistic regression the same pattern holds: β = 0.6377, so a 10-percentage-point higher margin multiplies the odds of being a high-ROA firm by about 1.066.

Margin efficiency is the dominant linear driver of financial performance. Also, leverage is not a simple linear warning sign in this data, and sector adds only marginal signal.
